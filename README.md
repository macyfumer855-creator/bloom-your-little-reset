# Bloom — Your Little Reset 🌷

Bloom is a self-care web app designed to help you slow down, build healthy habits, track your mood, and celebrate small wins.

## ✨ About the Project

Life can get overwhelming, and sometimes we all need a little reset. Bloom is designed to make self-care feel simple, gentle, and enjoyable through a soft, calming interface.

## 🌸 Features

- **Daily Dashboard:** A place to check in with yourself.
- **Habit Tracker:** Build routines and keep track of your progress.
- **Mood Journal:** Reflect on your feelings and record your thoughts.
- **Water Tracker:** Keep track of your daily hydration.
- **Garden and Streaks:** Celebrate your consistency as you grow.
- **Progress Dashboard:** View your progress over time.
- **Dark Mode:** Switch to a darker appearance when you prefer.
- **Responsive Design:** Designed to be comfortable to use across different screen sizes.

*Features depend on the functionality implemented in the current version of the app.*

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 How to Run Bloom

1. Open the project's GitHub repository.
2. Download or clone the repository.
3. Open `index.html` in a web browser.

## 💗 The Vision

Bloom is a personal project focused on making everyday self-care feel less like a chore and more like a small act of kindness toward yourself.

**You don't have to bloom all at once. 🌱**
